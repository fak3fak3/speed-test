# speed-test

Консольный скрипт для замера скорости скачивания. Делает несколько запросов к адресу **последовательно**, каждый раз дожидаясь полного ответа, и печатает:

- время и скорость каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- итоговую скорость скачивания.

Нужен Python 3.9+. Внешних зависимостей нет, используется только стандартная библиотека.

## Запуск

```bash
python3 speedtest.py https://proof.ovh.net/files/10Mb.dat
```

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | — (обязательный) | Адрес `http://` или `https://` |
| `-n`, `--count` | `10` | Количество запросов |
| `-t`, `--timeout` | `30` | Таймаут в секундах на подключение и на каждое чтение из сокета (это не лимит на весь запрос) |

Пример вывода:

```
Адрес: https://proof.ovh.net/files/10Mb.dat
Запросов: 3, таймаут: 30 с

[1/3]    8.459 с      10.49 МБ       9.92 Мбит/с
[2/3]   10.297 с      10.49 МБ       8.15 Мбит/с
[3/3]    6.238 с      10.49 МБ      13.45 Мбит/с

Итог
  Успешных запросов:     3 из 3
  Среднее время запроса: 8.331 с
  Скачано всего:         31.46 МБ
  Скорость скачивания:   10.07 Мбит/с (1.26 МБ/с)
```

Коды выхода: `0` — хотя бы один запрос прошёл успешно, `1` — все запросы завершились ошибкой, `2` — неверные аргументы, `130` — прервано через Ctrl+C.

## Единицы измерения

- **Скорость — Мбит/с** (мегабиты в секунду, 1 Мбит = 10⁶ бит). В этих единицах указывают тарифы провайдеров и показывают результаты speedtest-сервисы. В скобках та же скорость в **МБ/с** (1 МБ = 10⁶ байт, то есть Мбит/с ÷ 8).
- **Объём — МБ**, десятичные: 1 МБ = 1 000 000 байт (не MiB).
- **Время — секунды**.

## Как считается

- **Время запроса** — от отправки запроса до получения последнего байта тела ответа. Сюда входят DNS, установка TCP/TLS-соединения и редиректы: каждый запрос открывает новое соединение.
- **Объём** — число байт тела ответа, полученных по сети. Заголовки не учитываются. Скрипт отправляет `Accept-Encoding: identity`, поэтому сервер не сжимает ответ и байты считаются честно.
- **Среднее время** — сумма времени успешных запросов, делённая на их количество.
- **Скорость** = общий объём × 8 / суммарное время успешных запросов. Скорости отдельных запросов не усредняются: такое среднее завышало бы результат.
- Ответ читается кусками по 64 КБ и не хранится в памяти, так что можно качать большие файлы.
- Скрипт отправляет `Cache-Control: no-cache`. CDN может его проигнорировать, и тогда замер покажет скорость до ближайшего узла CDN.
- Ошибочные запросы (HTTP 4xx/5xx, таймаут, обрыв соединения) выводятся в лог и в итог не входят.

## Тесты

```bash
python3 -m unittest discover -s tests -v
```

Тесты поднимают локальный HTTP-сервер, сеть им не нужна. Они проверяют:

- что запросы идут строго последовательно и каждый ждёт полного ответа;
- подсчёт байт и формулу скорости;
- заголовки запроса и переход по редиректам;
- обработку ошибок HTTP, таймаутов и недоступного сервера;
- значения по умолчанию и проверку аргументов;
- запуск как скрипта.

В GitHub Actions ([.github/workflows/tests.yml](.github/workflows/tests.yml)) тесты запускаются на каждый push и PR: на Ubuntu с Python 3.9–3.13, а также на macOS и Windows с Python 3.13.
